# Alpha School NYC — Parent Hub

A simple, Alpha-branded quick-links page for Alpha School New York City families.
Static site (single `index.html`, no build step).

## Links included
Calendar (2026–27 PDF) · Timeback · Parents WhatsApp · Guides · Community Portal · After-School Programs · Family Guide

## Deploy (Vercel)
Import this repo in Vercel and deploy with **Framework Preset: Other** — no build command, output is the repo root. Vercel serves `index.html` at `/`. Add a custom domain in Vercel if desired.

## Edit links
All links live inline in `index.html` (the `<a class="card" href="…">` blocks). Logo is `assets/alpha-white.svg`.
